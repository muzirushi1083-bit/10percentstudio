# 🚀 10%studio - Official Workspace

Welcome to **10%studio**!
10%studio は、AIエージェントチームが自律的に市場リサーチ、企画、開発、デザイン、運営を行い、CEO（ユーザー様）が意思決定と最終承認を行う**自律型ゲーム開発スタジオ**です。

---

## 🎯 経営ビジョン & 収益モデル
- **ミッション**: 最小限のコスト（初期費用0円ベース）とリソースで、高中毒性・高収益なスマホゲームを開発・運用する。
- **展開戦略**:
  1. **Phase 1 (Web / PWA)**: スマホ・PCブラウザで遊べるハイパーカジュアルゲームを高速開発・即時公開。Web広告による初期収益化。
  2. **Phase 2 (ネイティブアプリ展開)**: 検証成功タイトルを iOS (App Store) / Android (Google Play) へパッケージ移植。
  3. **Phase 3 (スケールアップ)**: 得られた利益を再投資し、中規模カジュアルゲームや放置ゲームへの拡張。

---

## 🏛️ 10%studio 組織構造 (5部署体制)

```
[ CEO (ユーザー様) ] : 最終承認・方向性決定
       │
[ COO (AI統合管理) ] : 全部署の進捗管理・提案合成・自律推進
       ├─ [ 1. 経営企画・マーケティング部 ] : 市場調査・収益化モデル設計・ASO
       ├─ [ 2. 企画・ゲームデザイン部 ]     : ゲーム仕様書・レベルデザイン・中毒性設計
       ├─ [ 3. 開発・技術部 (Engineering) ]  : クライアント開発(Web/PWA)・コード品質・自動化
       ├─ [ 4. アート・クリエイティブ部 ]   : UI/UX・アセット制作・演出デザイン
       └─ [ 5. 運用品質・アナリティクス部 ] : QAデバッグ・KPI計測・改善イテレーション
```

## ⚡ 自律型運用プロトコル
AIエージェントは常に**「リサーチ -> 企画策定 -> プロトタイプ開発」**を先行して行い、CEOには**選択肢と要点**を提示します。CEOは1日5分程度での確認・フィードバック・指示のみで運用が継続します。
